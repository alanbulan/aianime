- 新构件将说明换行统一成 `LF` 后再生成清单；聚合旧构件时只对说明字段的 `CRLF` 与 `LF`
  做等价比较，仍拒绝实际文本差异、其他空白变化、错误版本、缺失平台及任何校验和不符。
  不重写原清单、安装包或签名 YAML，继续核验原始字节及校验和清单。
- 新增独立 `publish-desktop.yml`，仅允许手动提供原构建运行编号，只有一个云端发布任务。
  不含打包矩阵、编译、FFmpeg 构建、原生产物暂存或签名步骤。
- 发布前验证同一官方仓库、可信分支或版本标签、固定构建工作流、已完成运行、三个成功打包任务、
  三份未过期构件及相同源码 SHA。拒绝 Fork、PR、未完成构建、缺失或过期产物。
- 从原源码 SHA 读取版本与发布说明，使用修复后的工具进行合并与发布，避免工具更新后错配版本。

- 与正常构建使用相同并发组，避免两条工作流同时发布；未来新构件保留期从一天改为七天，
