# v1.1.15

## User-facing Highlights (zh)

- **来源提交**: 本版本由 Gitee Go 根据提交 `7ca5812b3b65ebd147569976525e415c29be9107` 自动生成，流水线构建编号为 `12`。
- **变更摘要**: fix(desktop): 修复 Hermes 空响应与 LiteLLM 打包缺失 问题定位：Hermes 0.19 在旧 ACP 会话因历史模型提供方无法恢复时，会返回成功的 JSON-RPC 外壳但 result 为 null；客户端此前仅检查 error 字段，误把恢复失败当成成功，随后 prompt 命中不存在的会话并形成空回复。 协议修复：session/load 只有在 result 非空时才视为恢复成功；result 为空时沿用现有 session/new 分支创建新会话，不增加提示重放，不重复执行工具或任务。 打包修复：PyInstaller 显式收集 litellm.containers 数据，并在桌面后端启动阶段校验 containers/endpoints.json，避免构建角色、场景和剧集任务运行到 1% 后才因缺文件失败。 验证记录：AI 助手与桌面相关 Python 回归 222 项通过，Electron 测试 74 项通过，前端架构回归 398 项通过，桌面 TypeScript 检查通过；重新构建 PyInstaller 后端并实测 socket_bound 成功，产物内 endpoints.json 共 5 个端点且无缺文件错误。
- **版本同步**: Python 包、Electron 安装器、前端版本兜底、依赖锁文件和 README 已统一更新为 1.1.15。
- **更新提示**: 更新窗口将展示本版本记录；安装完成后请重新启动客户端，使本地后端、Hermes 和 Electron 主进程全部切换到新版本。
