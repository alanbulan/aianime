# v1.1.19

## User-facing Highlights (zh)

- **来源提交**: 本版本由 Gitee Go 根据提交 `60028efc7288a9e5e5a1ce4dc60df3f72ebcd57e` 自动生成，流水线构建编号为 `21`。
- **变更摘要**: fix(desktop): 修复中文项目的 Ladybug 图数据库初始化 问题原因：Windows 版 Ladybug pybind 原生绑定将 Python Unicode 路径按窄字符串传递。英文项目能够正常创建图数据库，但项目名包含中文时，即使父目录已经存在，原生库仍返回 Error 3；Cognee 随后把新库创建失败误判为旧库迁移，最终对不存在的 .pkl 抛出 FileNotFoundError。 修复内容：仅在 Windows 且数据库路径包含非 ASCII 字符时，在进入 Ladybug pybind 的瞬间按系统文件编码传递字节路径，调用后恢复原始 Unicode 逻辑路径；不改项目名称、不迁移项目目录，也不改变 macOS/Linux 行为。 质量保障：新增中文目录实际建库回归测试；冻结后端冒烟改为在中文项目目录创建并查询 Ladybug 数据库，同时继续校验 Cognee 52 个提示模板、25 个迁移、LiteLLM 资源及 UTF-8 输出。 验证记录：Cognee/导入相关测试 24 项通过，桌面测试 75 项通过，架构门禁 153 项通过，Ruff 通过；源码在 UTF-8 与 GBK 环境均通过；PyInstaller 冻结后端构建成功，打包 EXE 中文路径冒烟通过。
- **版本同步**: Python 包、Electron 安装器、前端版本兜底、依赖锁文件和 README 已统一更新为 1.1.19。
- **更新提示**: 更新窗口将展示本版本记录；安装完成后请重新启动客户端，使本地后端、Hermes 和 Electron 主进程全部切换到新版本。
