# v1.1.23

## User-facing Highlights (zh)

- **来源提交**: 本版本由 Gitee Go 根据提交 `eccb4276074392363a50730d8ac61bc75c3e5756` 自动生成，流水线构建编号为 `30`。
- **变更摘要**: fix(desktop): 修复知识图谱向量维度与全任务进度日志 - 根据最新快速导入任务数据库和 backend.log 定位：远端向量模型调用已经成功，但返回 4096 维向量，本地 Cognee/LanceDB 索引按 1024 维建模，最终在 LanceDataPoint 校验阶段失败。 - 将本地索引维度作为 OpenAI embeddings dimensions 请求契约发送给模型网关，并在入库前校验实际向量长度；维度不一致时返回明确的本地/远端维度说明，不再暴露难以理解的 Pydantic too_long 错误。 - 恢复 Cognee 默认资源调度，移除 chunks_per_batch=1 与 data_per_batch=1 的单线程限制；保留整条流水线不盲目重放，避免重复远端写入和重复计费。 - 将向量网关改为一次安装的全局包装器与 ContextVar 请求上下文，保证并发调用的维度、响应头、请求 ID 和计费信息互相隔离，避免恢复并发后发生全局函数串线。 - 知识图谱构建和向量索引阶段新增真实模型活动进度：持续展示文本调用完成数、向量批次与条数、当前并发路数、耗时及阶段估算百分比。 - 统一任务状态契约：快速导入、角色/场景/道具、脚本、图片、音频、视频和自由区等任务的 current_task 阶段变化自动进入日志并去重；任务列表直接显示当前子阶段。 - 任务详情概览新增实时耗时、进度条和内嵌实时日志，保留完整日志页；补齐中英文 I18N，不再要求切换标签或滚动到底部才能看到执行过程。 - 已通过 Electron 78 项、前端架构 398 项、任务中心组件 16 项、Python 流水线关键路径 77 项、知识图谱与任务进度 43 项，以及前后端类型检查、Ruff 和 git diff 校验。
- **版本同步**: Python 包、Electron 安装器、前端版本兜底、依赖锁文件和 README 已统一更新为 1.1.23。
