## User-facing Highlights (zh)

- **来源提交**: 本版本由 Gitee Go 根据提交 `b56aabef393cfd304b0175e8f2e72ba43ca4c2a6` 自动生成，流水线构建编号为 `14`。
- **变更摘要**: fix(ai): 修复助手小说摄入失败与 Hermes 并发冲突 问题原因：助手技能文档仍使用旧版摄入请求合同，ai_anime_post 在缺少请求体时直接调用 /ingest/start，后端按真实 schema 返回 422；失败后的第二次写调用又被单轮写操作保护拦截。 摄入修复：新增 ai_anime_start_ingest 专用业务工具，从当前云端或 BYOK 用途分配读取 TEXT 与 EMBEDDING 模型，连同 filename、rebuild 和可选 spine_template 一次性提交严格请求体。通用 ai_anime_post 明确拒绝摄入启动路径，防止继续猜测接口参数。 并发修复：在 HermesSdkThread 中用轮次锁串行化预热和完整 ACP 对话流，避免多个协程同时读取同一子进程 stdout 导致 readuntil 并发异常。 合同同步：更新主技能、流水线详情和 API 参考，明确摄入模型必填字段、专用工具入口、覆盖重建确认规则以及错误即停约束。 验证记录：Ruff 全量通过；Python 相关回归 403 项及流水线关键路径 35 项通过；Electron 74 项、前端架构 398 项、两端类型检查与 CE 正式构建全部通过。
